Ram0 serves a Bearer-authenticated Streamable HTTP endpoint at `/mcp`. It exposes six account-scoped tools and is separate from the hosted Mem0 Platform MCP.

## Choose a connection

Direct MCP is tools-only. The [full automation plugin](/integrations/ram0-plugin) registers the same tools and adds lifecycle retrieval, bounded durable capture, and workflow skills. Do not register both connections in one client.

## Install the full plugin

```bash
# Claude Code
claude plugin marketplace add https://github.com/olhapi/ram0-plugins.git
claude plugin install ram0@ram0-plugins

# Codex
codex plugin marketplace add https://github.com/olhapi/ram0-plugins.git
codex plugin add ram0@ram0-plugins
```

Restart the client and review/trust the lifecycle hooks. In Codex, use `/hooks`. The trusted startup hook installs the bundled CLI; MCP itself starts directly from the plugin bundle.

Create an API key on the dashboard; it is shown once. Then configure and verify:

```bash
ram0 setup --url 'https://ram0.example.lan'
ram0 config test
```

`ram0 setup` reads the key without echo and stores it with the URL at `~/.config/ram0/config.json` (`0700` directory, `0600` file). Plugin install and update preserve that config. The key is sent only as `Authorization: Bearer` to the configured endpoint and is never stored as memory or logged. Normal setup requires no environment exports.

## Update the full plugin

```bash
# Codex
codex plugin marketplace upgrade ram0-plugins

# Claude Code
claude plugin marketplace update ram0-plugins
claude plugin update ram0@ram0-plugins
```

Restart after upgrading. Native updates preserve the config and require no checkout, cache deletion, or plugin removal.

## Available tools

| Tool | Purpose |
| --- | --- |
| `remember` | Store one user-authored memory. |
| `search_memories` | Search with a natural-language query. |
| `list_memories` | List the account's memories. |
| `get_memory` | Read an account-owned memory by UUID. |
| `update_memory` | Update an account-owned memory by UUID. |
| `forget_memory` | Delete an account-owned memory by UUID. |

The API-key owner determines the account-wide namespace; clients cannot choose another owner, agent, run, or expiration scope.

## Workflow skills

- Write: `remember`
- Browse: `peek`, `tour`
- Delete: `forget` (confirmation required)
- Portable data: `export`, `import`
- Quality: `memory-reviewer`, `dream`, `stats`
- Setup: `health`, `onboard`
- Policy: `ram0-memory`

Plugin installation includes all skills automatically. OpenCode discovers all 12 bundled skills; `npx skills add https://github.com/olhapi/ram0 --skill ram0-memory` installs only the standalone policy skill.

## Verify

Run `ram0 config test`, confirm the MCP starts without an environment-variable warning, and invoke `health`. Call `remember`, start a new task, then use `search_memories` to verify recall.

## Migration

If `ram0-plugins` points at a local marketplace, replace it once. This local marketplace migration preserves `~/.config/ram0/config.json`; normal future updates use the native commands above.

```bash
# Codex
codex plugin remove ram0@ram0-plugins
codex plugin marketplace remove ram0-plugins
codex plugin marketplace add https://github.com/olhapi/ram0-plugins.git
codex plugin add ram0@ram0-plugins

# Claude Code
claude plugin uninstall ram0@ram0-plugins
claude plugin marketplace remove ram0-plugins
claude plugin marketplace add https://github.com/olhapi/ram0-plugins.git
claude plugin install ram0@ram0-plugins
```

Remove any duplicate direct Ram0 MCP entry before enabling the plugin.

## Direct MCP and troubleshooting

The config-aware stdio bridge can instead be registered directly:

```bash
codex mcp add ram0 -- python3 ~/.local/share/ram0/mcp_stdio_adapter.py
claude mcp add ram0 --scope user -- python3 ~/.local/share/ram0/mcp_stdio_adapter.py
```

- Rotate a key with `ram0 config set-key`.
- Repair permissions with `chmod 600 ~/.config/ram0/config.json`.
- Missing config: rerun `ram0 setup`. Unreachable endpoint: check `ram0 config show`, then `ram0 config test`.

The full plugin never sends or saves raw prompts, transcripts, file dumps, complete code/diffs, credentials, or identities.
